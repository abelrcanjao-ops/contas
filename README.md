# Contas

Controle financeiro simples, por mês: despesas **A PAGAR** (vermelho) e **PAGO** (verde), total a pagar sempre visível,
parcelas automáticas, tema escuro e cores personalizáveis. Funciona offline e guarda os dados **somente no aparelho**.

## Instalar no iPhone
1. Abra o endereço do app no **Safari**.
2. Toque em **Compartilhar** → **Adicionar à Tela de Início**.

## Levar os dados do app Android
No Android: **⚙ Configurações → Exportar dados** (gera `contas-backup-AAAA-MM-DD.json`).
No iPhone: **⚙ Configurações → Importar dados** e escolha o arquivo.
