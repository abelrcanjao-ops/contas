# Contas

Controle financeiro simples, por mês: despesas **A PAGAR** (vermelho) e **PAGO** (verde), total a pagar sempre visível,
parcelas automáticas, tema escuro, cores personalizáveis e relatório do mês em PDF.
Funciona offline e guarda os dados **somente no aparelho**.

## Instalar no iPhone
1. Abra o endereço do app no **Safari**.
2. Toque em **Compartilhar** → **Adicionar à Tela de Início**.

## Como usar
- **+ Despesa**: nome, valor em reais e, se quiser, parcelas (as próximas parcelas já aparecem nos meses seguintes).
- **Segurar** uma despesa: editar. **Arrastar** a lista para os lados: trocar de mês.
- **⋮ → Configurações**: tema escuro, cores, relatório do mês (PDF) e backup.

## Levar os dados do app Android
No Android: **⋮ → Configurações → Exportar Dados** (gera `contas-backup-AAAA-MM-DD.json`).
No iPhone: **⋮ → Configurações → Importar Dados** e escolha o arquivo.
